# 📌 Project Overview

작심농장은  
사용자가 기록에 실패하더라도 쉽게 포기하지 않고  
다시 기록 흐름으로 돌아올 수 있도록 기획한 UX/UI 프로젝트입니다.

기존 습관 앱의  
'연속 기록 유지' 중심 구조에서 벗어나,

✔ 부담 없는 기록 경험  
✔ 빠른 행동 흐름  
✔ 재시작 가능한 UX 구조

에 집중하여 설계했습니다.

---

# 🧠 Core Concept

## 기존 습관 앱의 문제

```text
기록 실패
→ 연속 기록 끊김
→ 실패 감정
→ 서비스 이탈
```

---

## 작심농장의 접근 방식

```text
기록 실패
→ 상태 변화
→ 회복 가능 구조
→ 다시 시작 유도
```

---

# 🎯 Product Vision

> 실패 이후에도 사용자가 부담 없이 다시 시작할 수 있는 습관 기록 경험 제공

---

# 🔍 Problem Definition

기존 습관 관리 서비스는  
하루만 기록을 놓쳐도 연속 기록이 끊기거나  
처음부터 다시 시작해야 하는 경우가 많았습니다.

이 과정에서 사용자는  
실패에 대한 부담감을 느끼게 되고  
결과적으로 서비스 사용 자체를 중단하는 문제가 발생한다고 판단했습니다.

또한 기록 과정이 복잡하거나 입력 피로가 높은 경우  
습관 형성 이전에 행동 자체가 부담으로 느껴질 수 있다고 생각했습니다.

---

# 🧩 UX Strategy

## 1. 가벼운 시작

초기 진입 장벽 최소화

- 회원가입 입력 최소화
- 빠른 서비스 시작
- 복잡한 절차 제거

---

## 2. 꾸준한 기록

행동 허들 낮추기

- 클릭 중심 기록 구조
- 빠른 입력 흐름
- 즉각적인 피드백 제공

---

## 3. 다시 시작

재진입 경험 설계

- 회복 가능한 규칙 구조
- 상태 변화 기반 피드백
- 누적 기록 시각화

# 📚 What I Learned

이번 프로젝트를 통해  
사용 경험은 단순히 기능을 많이 제공하는 것이 아니라,

사용자가 부담 없이 행동을 이어갈 수 있도록 만드는 과정이라는 점이라는 점을 배울 수 있었습니다.

특히 기록 실패 이후 다시 시작할 수 있는 흐름을 기획하며  
사용자의 감정 변화까지 고려한 UX 설계의 중요성을 경험했습니다.

또한 기획 단계에서 구상했던 상태 변화와 인터랙션 일부는  
실제 구현 단계에서 완성하지 못한 아쉬움이 있었습니다.

이 경험을 통해  
아이디어를 설계하는 것뿐 아니라,

기획한 UX를 실제 화면과 인터랙션으로 연결하는 과정의 중요성을 느낄 수 있었습니다.
